# Enciclonario Americano 📖🌎

**Enciclonario Americano** es un portal educativo web diseñado para reunir el conocimiento enciclopédico y la riqueza léxica de todos los países hispanohablantes de América. Proporciona un entorno didáctico, limpio, de acceso gratuito y apto para niños y estudiantes.

---

## 🚀 Características Principales

- **Doble Modalidad Integrada**: 
  - **Enciclopedia de América**: Artículos detallados sobre historia, geografía, naturaleza, cultura y monumentos del continente.
  - **Diccionario Hispanoamericano**: Definiciones de modismos, términos y expresiones dialectales aprobadas para uso académico y familiar.
- **Buscador Dinámico e Interactivo**: Permite filtrar entradas por palabras clave, términos gramaticales o temáticas.
- **Filtro por Ámbito Geográfico**: Selección rápida de contenidos por país (Uruguay, Argentina, México, Colombia, Perú, Chile, Venezuela, Ecuador, Bolivia, Centroamérica y Caribe).
- **Diseño Adaptable y Accesible**: Interfaz optimizada con tipografía académica, iconos de *Google Material Symbols* y compatibilidad móvil/escritorio.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica del sitio web.
- **CSS3**: Estilos adaptativos, diseño dinámico y modal informativo.
- **JavaScript (ES6)**: Lógica de filtrado en tiempo real, renderizado dinámico de tarjetas y cambio de modos.
- **Google Material Symbols**: Iconografía limpia e institucional sin emojis.
